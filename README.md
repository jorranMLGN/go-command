# Go Command
    
## Description
This project is a Go command that provides a simple way to manage and execute various tasks related to development.
Create your own commands and add them to the command list.
## Features
- Easy to use command line interface
- Customizable commands
- Toggle between different commands
- Built-in help command
- Support for multiple platforms
