# 🚀 Go Command Utility

> **⚠️ Work in Progress:** This project is actively being developed. Features may change, and not everything is fully implemented yet.

A powerful and flexible command-line tool written in Go, designed to streamline your development workflow. Easily manage, execute, and customize a variety of tasks with a clean and intuitive interface.

---

## ✨ Features

- ⚡ **Simple CLI Interface** – Effortlessly run tasks with user-friendly command-line options.
- 🛠️ **Custom Commands** – Define your own commands and add them to the task list.
- 🔄 **Command Toggling** – Switch between different commands based on your needs.
- 📖 **Built-in Help** – Access a help menu directly from the terminal.
- 🌐 **Cross-Platform Support** – Works seamlessly on multiple operating systems.

> 🔧 More features are planned and in progress. Stay tuned!

---

## 🧰 Getting Started

Clone the repository and start building your own development command suite!

---

## 🏗️ Build Instructions

To build a local snapshot of the command:

```bash
goreleaser build --snapshot --clean
```

> 💡 Make sure you have [`goreleaser`](https://goreleaser.com/) installed and properly configured.
